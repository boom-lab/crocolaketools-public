First tagged release of CrocoLakeTools, the Python package that builds
CrocoLake — a database of oceanographic observations developed for the
NSF-sponsored CROCODILE project.

## What it does

Two submodules, `downloader` and `converter`, retrieve public ocean
observation datasets and convert them to CrocoLake's parquet format, plus
`merge_crocolake` to assemble the converted datasets into one queryable
data lake.

Sources with a downloader, a converter, or both: Argo (GDAC and QC), GLODAP,
Spray Gliders, Saildrones, Oleander XBT, IOOS Gliders, SPOTS.

Each dataset is described by one entry in `datasets.yaml`, so adding a source
or repointing an existing one is a configuration change (not a code
change). Conversion runs on dask, sized per dataset in `dask_cluster.yaml`.

Requires Python 3.11 or 3.12.

## Configuration

Configuration lives in a directory holding `datasets.yaml` and
`dask_cluster.yaml`, named either by the `CROCOLAKE_CONFIG_DIR` environment
variable or by `--config-dir` on any entry point:

```
glodap2parquet --config --config-dir /path/to/my-config
```

The package ships `datasets.example.yaml` and `dask_cluster.example.yaml` as
templates. Copy them, edit the paths, and point `CROCOLAKE_CONFIG_DIR` or
`--config-dir` at the copy. The repository's `tests/config/` is a working
example pointing at the small dataset committed under `tests/fixtures/`. The
configuration directory must contain both files or an error is raised.
